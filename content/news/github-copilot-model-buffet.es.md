La última actualización de GitHub Copilot apuesta todo por la libertad de elección: Kimi K3, Grok 4.6 de xAI y el propio MAI-Code-1.1-Flash de Microsoft se suman al selector de modelos, junto con nuevos controles de esfuerzo de razonamiento Bajo/Medio/Alto. Copilot CLI también fue reconstruido sobre un runtime nativo en Rust, así que va notablemente más rápido en la terminal. Parece que GitHub apuesta a que ningún modelo reinará para siempre, así que mejor dejarte elegir el mejor para cada tarea.
