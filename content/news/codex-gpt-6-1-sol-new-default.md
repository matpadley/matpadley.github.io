Codex just changed its default brain. Since version 0.161, new sessions run on GPT-6.1 Sol, which OpenAI's release notes describe as the faster option, so you don't have to pick it yourself.

The same release lets you choose your microphone and speaker for voice conversations, which means talking to your coding agent is becoming a normal thing. Follow-up patches fixed a nasty crash on multi-line questions, so if Codex was acting weird for you, update.
