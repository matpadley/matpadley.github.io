GitHub Copilot now comes with a built-in sandbox, and it's included in your plan. Anything Copilot runs on your machine gets put in a little fenced-off box, with limits on which files it can touch, whether it can get online, and whether it can see your Git credentials.

It works in the CLI, the Copilot app and VS Code on Windows, Mac and Linux, and companies can lock the rules so developers can't loosen them. After this week's news about agents wandering where they shouldn't, a seatbelt that's on by default feels pretty timely.
