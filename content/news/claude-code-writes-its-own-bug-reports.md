Anthropic just shipped something delightfully weird: Claude Code can now write its own bug reports. If a tool call keeps failing, or Claude realizes it messed something up, it drafts a feedback report on the spot and hands it to you to review before sending via `/feedback`. It's the closest thing to an AI assistant saying "yeah, that was my bad" — and honestly, more software should work this way.
