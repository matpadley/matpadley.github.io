GitHub Copilot's latest update is all about choice: Kimi K3, xAI's Grok 4.6, and Microsoft's own MAI-Code-1.1-Flash are all rolling into the model picker, alongside new Low/Medium/High thinking-effort dials. Copilot CLI also got rebuilt on a native Rust runtime, so it's noticeably snappier in the terminal. Feels like GitHub is betting that no single model wins forever, so why not let you pick the best one for the job.
