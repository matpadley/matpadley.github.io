Anthropic acaba de lanzar algo genuinamente curioso: Claude Code ahora puede escribir sus propios informes de errores. Si una herramienta falla varias veces, o Claude se da cuenta de que metió la pata, redacta al instante un informe para que lo revises antes de enviarlo desde `/feedback`. Es lo más parecido a un asistente de IA diciendo «sí, fue culpa mía» — y sinceramente, más software debería funcionar así.
