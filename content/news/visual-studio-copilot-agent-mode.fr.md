La mise à jour de juillet de Microsoft a ajouté une option Agent (Preview) dans Copilot Chat pour Visual Studio, construite sur le même SDK qui alimente le CLI GitHub Copilot — avec en plus des commentaires de revue de code directement dans l'éditeur, sans quitter votre fichier.

La revue de code de Copilot est aussi passée en disponibilité générale avec le support des compétences d'agent et des serveurs MCP, pour tous les abonnés Pro, Pro+, Business ou Enterprise. Ça ressemble moins à une mise à jour mineure qu'à Visual Studio qui rattrape enfin le workflow orienté agents que les utilisateurs de VS Code ont depuis un moment.

Si vous êtes resté sur VS Code parce que Visual Studio semblait à la traîne, ça vaut peut-être le coup d'y rejeter un œil.
