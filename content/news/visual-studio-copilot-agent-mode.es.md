La actualización de julio de Microsoft agregó una opción de Agente (Preview) en Copilot Chat para Visual Studio, construida sobre el mismo SDK que impulsa el CLI de GitHub Copilot — además de comentarios de revisión de código directamente en el editor, sin salir del archivo.

La revisión de código de Copilot también pasó a disponibilidad general con soporte para habilidades de agente y servidores MCP, para todos los usuarios Pro, Pro+, Business o Enterprise. Se siente menos como una actualización menor y más como que Visual Studio por fin alcanza el flujo de trabajo centrado en agentes que los usuarios de VS Code ya tenían.

Si te quedaste en VS Code porque Visual Studio se sentía atrasado, vale la pena echarle otro vistazo.
