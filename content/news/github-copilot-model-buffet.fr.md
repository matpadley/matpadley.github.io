La dernière mise à jour de GitHub Copilot mise tout sur le choix : Kimi K3, Grok 4.6 de xAI et le MAI-Code-1.1-Flash maison de Microsoft rejoignent tous le sélecteur de modèles, avec en prime de nouveaux réglages d'effort de réflexion Faible/Moyen/Élevé. Copilot CLI a aussi été reconstruit sur un runtime Rust natif, donc c'est nettement plus rapide dans le terminal. On dirait que GitHub parie qu'aucun modèle ne restera roi éternellement, alors autant vous laisser choisir le meilleur pour chaque tâche.
