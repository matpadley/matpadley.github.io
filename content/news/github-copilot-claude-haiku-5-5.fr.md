GitHub Copilot vient d'ajouter Claude Haiku 5.5, le petit rapide de la famille Claude. Il est pensé pour le quotidien : petites modifs, tâches dans le terminal, et mini-agents qui font le gros du travail de fourmi. D'après GitHub, lors des premiers tests, il égalait Claude Sonnet 5 sur pas mal de tâches de code tout en utilisant bien moins de tokens et d'étapes.

Il arrive pour les offres Pro, Pro+, Max, Business et Enterprise, à peu près partout où vit Copilot (VS Code, JetBrains, Xcode, la CLI, même l'appli mobile). Le déploiement est progressif, donc si vous ne le voyez pas encore dans le sélecteur de modèle, patientez un jour ou deux.

Mon petit conseil : pour les corvées, essayez d'abord le petit modèle. Votre portefeuille vous dira merci.
