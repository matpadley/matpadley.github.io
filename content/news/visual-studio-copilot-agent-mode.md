Microsoft's July update gave Visual Studio a new Agent (Preview) option in Copilot Chat, built on the same SDK that powers the GitHub Copilot CLI — plus inline code review comments you can act on right in the editor without leaving your file.

Copilot's code review also just went GA with support for agent skills and MCP servers, for anyone on Pro, Pro+, Business, or Enterprise. Feels less like an incremental update and more like Visual Studio catching up to the agent-heavy workflow VS Code users have had for a while.

If you've been living in VS Code because Visual Studio felt behind, it might be worth another look.
