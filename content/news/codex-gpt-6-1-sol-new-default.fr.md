Codex vient de changer de cerveau par défaut. Depuis la version 0.161, les nouvelles sessions tournent sur GPT-6.1 Sol, présenté dans les notes de version comme l'option la plus rapide, donc inutile de le choisir vous-même.

La même version permet de choisir votre micro et vos haut-parleurs pour les conversations vocales : parler à son agent de code devient normal. Des correctifs ont ensuite réglé un vilain plantage sur les questions multilignes, donc si Codex se comportait bizarrement, mettez à jour.
