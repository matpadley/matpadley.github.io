OpenAI a réduit le prix de GPT-5.6 Luna de 80 % cette semaine et a fait basculer la fonction Auto-review de Codex dessus — la passe automatique qui vérifie le travail de votre agent avant vous. Résultat, environ 10 fois moins cher pour quiconque compte sur Auto-review pour garder un œil sur les runs agentiques de Codex.

Le timing semble calculé aussi : ça tombe pile au moment où la fenêtre promo de Claude Sonnet 5 se referme fin août. Les outils de code IA ne se battent plus seulement sur les capacités, ils se battent sur qui rend la surveillance d'un agent la moins chère.
