ClubMonitor is a multi-tenant app for running sports club leagues and cups — darts, crown green
bowls, whatever a club plays — with platform-wide competitions spanning clubs alongside each club's
own internal ones. It is built as a .NET 10 Minimal API with EF Core, fronted by an Avalonia app
targeting web, tablet and phone, and deployed to Azure with Bicep.

These entries are the build log, written as the work happened: what changed, why, and what turned out
to be wrong about the previous entry.
